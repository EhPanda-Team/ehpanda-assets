# EhPanda assets

Images for EhPanda that are served from here rather than kept in the app repository.

## `altstore/iphone/`

The iPhone screenshots of the EhPanda listing in AltStore and SideStore, `01-home.png` to
`07-more.png`. The number gives the order in the listing.

Each is a 1260 × 2736 PNG. The source files link to them by their raw URL, for example
`https://raw.githubusercontent.com/EhPanda-Team/ehpanda-assets/main/altstore/iphone/01-home.png`,
with `width` 1260 and `height` 2736. AltStore and SideStore read the width and height as whole
numbers, so keep them in pixels. Renaming or moving a file breaks the listing until the source files
are updated.
